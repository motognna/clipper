# Muzică de fundal (monetizare-safe)

Pune aici fișiere `.mp3` / `.wav` / `.m4a` / `.ogg`. Scriptul alege câte unul la întâmplare pentru fiecare clip,
îl pune sub voce (ducking automat) și îl termină cu fade-out.

**Folosește DOAR muzică la care ai dreptul pentru conținut monetizat**, altfel primești Content ID claims
sau demonetizare:

- **YouTube Audio Library** (Studio -> Audio Library) – filtrează pe „Attribution not required".
- **Pixabay Music** (licență Pixabay – fără atribuire, monetizare permisă).
- **Uppbeat** / **Free Music Archive** (doar piesele CC0 / CC-BY, cu atribuire în descriere dacă e cerută).
- Piese pe care le-ai cumpărat/generat tu (ex. Suno/Udio pe plan plătit cu drepturi comerciale).

NU folosi melodii din radio-ul jocului sau piese comerciale populare. Păstrează dovada licenței (screenshot/link).
